APRENDE A TOCAR

Tutoriais 📖

Escolhe uma música e segue a sequência de teclas.

⌨️ Como funcionam as teclas?

Cada tecla representa uma nota da guitarra virtual. Quando uma tecla fica iluminada, é a próxima nota do tutorial.

A → W → S → E → D → F

🐢 Alterar velocidade

Durante um tutorial podes alterar a velocidade.

  • 50% = muito lento
  • 75% = lento
  • 100% = normal
  • 125% = rápido
  • 150% = muito rápido

📤 Como postar um tutorial

  1. Vai a 📤 Criar.
  2. Escreve o nome da música.
  3. Coloca a sequência de teclas.
  4. Define o BPM.
  5. Adiciona uma descrição.
  6. Testa a sequência.
  7. Carrega em Publicar.

Nesta versão, os tutoriais ficam guardados no navegador através do armazenamento local.

COLOCAR ONLINE

Publica o GuitarWeb. 🌐

O site funciona como um ficheiro HTML único.

1️⃣ Guarda o ficheiro

Cria um ficheiro chamado:

index.html

Cola o código do site dentro dele.

2️⃣ Testa no computador

Abre o index.html no Chrome ou Edge.

Não precisas de instalar um servidor para testar esta versão.

3️⃣ Publica

Podes colocar o ficheiro num serviço de hospedagem estática, como GitHub Pages ou Netlify.

⚠️ Sobre os tutoriais da comunidade

Nesta versão, os tutoriais criados são guardados apenas no navegador da pessoa. Para que todos os utilizadores consigam ver os mesmos tutoriais, seria necessário ligar o site a uma base de dados e a um backend.
